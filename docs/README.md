# Dokümantasyon

GitHub ana sayfasında görünen güncel proje tanıtımı, kurulum komutları ve sistem akışları için kök dizindeki [README.md](../README.md) dosyasına bakabilirsiniz.

Bu dizin, proje geliştirme ve yardımcı dokümantasyon için ayrılmıştır:

- [DEPLOYMENT.md](./DEPLOYMENT.md): Production deployment, migrations, backups.
- [DATA_PROTECTION.md](./DATA_PROTECTION.md): Technical data protection measures.
- [PRE_LAUNCH_CHECKLIST.md](./PRE_LAUNCH_CHECKLIST.md): Checks to run on the server before go-live.
- [codex-komutlari.md](./codex-komutlari.md): Codex ile proje üzerinde çalışma notları.
- [setup-commands.sh](./setup-commands.sh): İlk scaffold döneminden kalma referans script. Güncel kurulum için kök README dosyasındaki komutlar kullanılmalıdır.
